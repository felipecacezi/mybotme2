# **App Name**: MyBotMe Landing Page

## Core Features:

- Landing Page Content: Landing page showcasing MyBotMe's features and benefits.
- Modern UI Design: A clean and modern design to appeal to users.
- Sign-Up Section: Section for new users to sign up and begin using MyBotMe.
- AI-Powered Chatbot: Generative AI provides chatbot functionalities that respond like a virtual assistant.
- WhatsApp API Integration: Whatsapp integration.
- FAQ section powered by AI: Display common questions and answers using AI as a tool.

## Style Guidelines:

- Primary color: A vibrant green (#2ecc71) to evoke trust and efficiency, commonly associated with business and technology.
- Background color: A light gray (#f2f2f2) provides a clean and modern backdrop, ensuring readability.
- Accent color: A calming blue (#3498db) for interactive elements and highlights, suggesting reliability and clear communication.
- Body and headline font: 'Inter', a grotesque-style sans-serif for a modern, objective feel.
- Use a set of clear, outline-style icons to represent key features of the chatbot application.
- Use a grid-based layout to ensure the page is responsive and looks good on all devices.
- Subtle animations on button hover and when loading new content.
